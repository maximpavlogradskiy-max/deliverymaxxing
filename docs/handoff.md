# Как продолжить в новой сессии

Состояние на 08.10.2026. Сводка и план — [plan.md](plan.md), постановка — [model.md](model.md),
выводы и список недостающих данных — [findings.md](findings.md).

## Перед началом

1. **Данные.** `data/raw/` в git не хранится — в новой сессии загрузите файлы заново под именами
   из README (выгрузка Вендора, витрины r_keeper, parquet пилота RIGA).
2. **Токены** — только в настройках окружения (меню облачного окружения → Edit), не в чате и не
   в файлах:
   - `YANDEX_OAUTH_TOKEN` — Метрика и Директ e-17453907 (Внуково);
   - `YANDEX_DIRECT_TOKENS` — `{"e-17392980": "…"}`, аккаунт с кампанией пилота.

## Первые шаги

```
python analysis/yandex_api.py daily e-17392980 2024-01-01   # расход по дням: 714026373, 700923383
python analysis/yandex_api.py goals 714026373 e-17392980     # стратегия и цели кампании пилота
python analysis/yandex_api.py conversions 714026373 e-17392980
```

Затем сопоставить дневной расход кампании 714026373 («Доставка» → /catalog/novaya_riga) с
заказами своей доставки RIGA (чеки с оплатой «… (соб.)» в `riga_orders`): включения, выключения
и резкие изменения бюджета — естественные эксперименты (прерванный ряд, разность разностей
против других ресторанов).

## Ждём от ресторана

- Комиссия: Вендор → «Статистика и финансы» → «Финансы» → «Удержания и возвраты» за 01.05–05.10;
  если там нет — акты у бухгалтерии.
- Графики смен поваров и курьеров RIGA за 2–3 месяца.
- Перевыгрузка `riga_orders` с номером стола и зала → число столов и загрузка зала по столам.
- Недельный отчёт продвижения Вендора (4 витрины) с 01.05.2026.
- Почему с 14.09 пропали отметки «Заказ готов» и кто снижал ставки 31.08.
